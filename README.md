# PRECISION RANGE

브라우저에서 실행되는 1인칭 3D 스포츠 사격장 시뮬레이터 (Three.js / WebGL2).

**▶ 플레이: https://charaing.github.io/precision-range/**

마우스로 조준하고, 3D 공간의 실제 광선-메시 교차 지점으로 점수를 계산합니다.
모든 총기·장비는 가상의 스포츠 모델이며, 반동/호흡 수치는 게임용 곡선입니다(실제 총기 성능 재현 아님).
3D 모델·텍스처·사운드는 모두 코드로 실시간 생성되며 외부 에셋을 사용하지 않습니다.

## 기능

| 구분 | 내용 |
|---|---|
| 총기 5종 | SPORT P-10(경기용 권총) · P-20(리볼버, 더블액션 격발 지연) · R-10(디옵터 경기 소총) · R-20(광학 스포츠 소총) · PRECISION X-1(볼트액션 장거리) |
| 광학 조준경 | 1·2·3·4·6·8·10·12·16배. Picture-in-Picture 렌더링(별도 카메라 → 렌더타깃 → 원형 렌즈 합성), 튜브·아이박스 그림자·배럴 왜곡·색수차·코팅 반사·레티클 4종·조명 레티클, 렌즈 밖 흐린 주변 시야, 휠로 부드러운 배율 변경 |
| 반동 | 총기별 스프링 곡선(시점 킥·총기 모델 후퇴/상승·카메라 충격·연사 시 흔들림 누적), 슬라이드/해머·실린더/볼트 애니메이션, 탄피 배출, 화면 진동 강도 설정 |
| 신체 시스템 | 비대칭 호흡 곡선, lub-dub 심박(긴장·피로에 따라 BPM 변화), 피로도, SHIFT 집중(숨 참기·흔들림 감소·게이지 소모·고갈 시 회복 대기·호흡 부채) |
| 사격장 5종 | 실내 클럽 레인 · 현대식 정밀 홀(전자 표적·책상 모니터) · 야외 레인(둑·깃발·나무) · 산악 장거리(300–1100m, 지형·설산) · 국제 대회장(관중·라이브 스코어보드) / 시간대별 조명 |
| 점수 | 10~1점 + 소수점(최대 10.9), 이너텐(X), 탄흔 데칼, 탄착 분포, 평균 탄착점(MPI), 그룹 크기, 10점 연속 기록 |
| 모드 | 자유 사격 · 10발 정밀 · 30발 · 60초 시간제한 · 장거리 도전 · 랜덤 팝업 표적 |
| 기록 | IndexedDB 저장(총기별 최고, 모드 평균, 총 사격/명중/정중앙, 총기별 플레이 시간, 최근 경기, 개인 최고) |
| 사운드 | WebAudio 합성 발사음(총기별), 환경별 스테레오 잔향 임펄스, 산악 메아리, 환경음, 심장 박동, 호흡, UI/점수음 |
| 그래픽 | PBR, 그림자, 환경맵(실제 씬 PMREM), MSAA/FXAA, 블룸, SAO(최고 품질·실내), 품질 4단계 |

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 | 조준 (Pointer Lock) |
| 좌클릭 | 발사 |
| 우클릭 | 조준 화면 전환 (설정에서 누르고 있기 방식 선택 가능) |
| 휠 | 조준경 배율 |
| R | 재장전 |
| SHIFT | 집중 (숨 참기) |
| ESC | 일시정지 · 설정 |
| F / T | 자유 사격: 거리 변경 / 표적 교체 |

## 로컬 실행

빌드 과정이 없습니다. 정적 서버만 있으면 됩니다.

```bash
python -m http.server 8000
```

## 구조

```
index.html        UI 마크업 + import map (three@0.160.0)
css/style.css     다크 미니멀 UI
js/main.js        부트스트랩 + 테스트 훅(window.PR)
js/game.js        렌더 파이프라인, 조준/반동/발사/명중 판정, 모드, 세션
js/ranges.js      사격장 5종 절차적 생성 + 시간대 조명
js/target.js      표적면/채점(scoreHit)/전자 모니터 그리기
js/weapons.js     총기·광학 정의, 절차적 3D 모델, 장갑 낀 손
js/scope.js       PiP 스코프 합성 셰이더
js/body.js        호흡·심박·피로·집중 모델
js/audio.js       합성 사운드 + 잔향
js/storage.js     IndexedDB 기록
js/ui.js          메뉴, 무기고 3D 미리보기, HUD, 결과 분석
```

## 테스트

브라우저 콘솔에서:

```js
PR.selfTest()            // 채점 경계값 단위 테스트
await PR.game.testShot(0.3, 0)   // 현재 표적의 (링1 반경 기준) 오프셋을 정조준 후 발사 → 3D 명중 기록 반환
```
